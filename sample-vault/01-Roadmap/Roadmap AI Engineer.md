# Roadmap — AI Engineer

> AI Engineer = constrói **produtos** sobre modelos (APIs/open-source), não treina modelos do zero. Foco: software + LLMs + dados + avaliação + produção.

## Fase 0 — Fundamentos (2-3 sem)
- [ ] Python sólido (typing, async, pydantic, pytest)
- [ ] Git, Docker, CLI, HTTP/REST, SQL
- [ ] Estatística/álgebra linear básica (vetores, similaridade, probabilidade)
- [ ] ML essencial: overfitting, métricas, train/val/test → [[Métricas e Avaliação de ML]]

## Fase 1 — LLM Foundations (2-3 sem)
- [ ] [[Transformers]] e atenção (intuição)
- [ ] [[Tokenização]], janela de contexto, temperatura
- [ ] [[LLMs]]: modelos, preço, latência, trade-offs
- [ ] [[Prompt Engineering]]
- [ ] [[Structured Outputs]]
- [ ] **Projeto:** CLI/chat com streaming e saída estruturada

## Fase 2 — Retrieval & Dados (3-4 sem)
- [ ] [[Embeddings]]
- [ ] [[Vector Databases]]
- [ ] [[RAG]] (chunking, hybrid search, reranking)
- [ ] [[Context Engineering]]
- [ ] **Projeto:** RAG sobre documentos com citações

## Fase 3 — Agentes & Tools (3-4 sem)
- [ ] [[Function Calling e Tool Use]]
- [ ] [[Agents]] (loops, planejamento, memória)
- [ ] [[MCP - Model Context Protocol]]
- [ ] [[Multi-Agent Systems]]
- [ ] **Projeto:** agente com ferramentas + MCP server próprio

## Fase 4 — Qualidade & Produção (3-4 sem)
- [ ] [[Evals]] (datasets, LLM-as-judge, regressão)
- [ ] [[Guardrails e Segurança]] (prompt injection)
- [ ] [[Observabilidade de LLMs]]
- [ ] [[Inference e Serving]], [[Caching e Custos]]
- [ ] Deploy (FastAPI/Next.js + Vercel/Docker), filas, rate limits

## Fase 5 — Especialização (contínuo)
- [ ] [[Fine-tuning]] (LoRA/QLoRA), destilação
- [ ] Modelos locais (Ollama, vLLM, llama.cpp)
- [ ] Multimodal (visão, áudio), voz em tempo real
- [ ] MLOps/LLMOps, orquestração (Temporal, workflows duráveis)

- [ ] Blog/threads sobre o que aprendeu
